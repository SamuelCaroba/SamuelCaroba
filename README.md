## 🚀 Projetos em destaque

### [BenchLab](https://github.com/SamuelzimMVP/BenchLab)

Suíte multiplataforma de benchmark e diagnóstico de hardware construída em Rust.

- CPU, memória, armazenamento e GPU Vulkan.
- GUI nativa e CLI em um único executável.
- Histórico SQLite, telemetria local, comparações, baselines e relatórios.
- Pacote portátil para Windows e arquitetura preparada para Linux.

**Tecnologias:** Rust, Vulkan, egui/eframe, SQLite e GitHub Actions.

### [ENEM Practice](https://github.com/SamuelzimMVP/ENEM-Practice)

Projeto educacional para prática do ENEM com experiência interativa e gamificada.

- Interface web responsiva.
- Progressão e elementos de gamificação.
- Backend em [enem-speedrun-backend](https://github.com/SamuelzimMVP/enem-speedrun-backend).

**Tecnologias:** JavaScript, HTML, CSS, Node.js e banco de dados.

### [Taskflow](https://github.com/SamuelzimMVP/taskflow)

Aplicação em TypeScript voltada à organização de tarefas e fluxo de trabalho.

### [Caroba Contabilidade](https://github.com/SamuelzimMVP/Caroba_Contabilidade)

Sistema web acadêmico de gestão contábil, desenvolvido com foco em automação e usabilidade.
